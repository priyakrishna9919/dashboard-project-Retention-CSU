Portal features
🔒
Public data only
Every metric sourced exclusively from IPEDS, CSU At-a-Glance, Common Data Set, and Ohio DHE — no FERPA-protected data, no Banner access required.
⚡
Fully interactive
All dashboards have live filters — year, college, student level, enrollment status. Charts update in real time. No page reloads. No backend.
📱
Mobile responsive
KPI rows collapse to 2-column grids, chart sections stack vertically. Works on tablet and phone for field access by deans and directors.
🎯
High-level design
Every chart and KPI maps to an executive question a VP, Provost, or Dean actually needs answered. Board-of-Trustees quality presentation.
🔄
CSU brand identity
Full CSU green and gold color system throughout. Playfair Display for executive headings, DM Mono for data values, DM Sans for interface text.
📊
Star schema ready
Designed with Power BI migration in mind. README includes full Fact_Enrollment + Dimension table schema with DAX measure recommendations.
